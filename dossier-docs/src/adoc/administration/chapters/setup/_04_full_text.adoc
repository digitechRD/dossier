[[_04_setup_full_text]]
=== {fulltext}

[IMPORTANT]
====
Le module {fulltext} est une application externe interconnectée avec le server {airs} et {arcadeged}. +

Elle permet l'ajout des fonctionnalités de :

* [underline]#recherches plein-texte# (appelées également _recherches à la google_)
* [underline]#rapprochement de documents# (_recherche de documents similaires)
====

Le paramétrage se fait via l'{adminAirs} ou directement dans le fichier {paramsXml}, via le nœud *ftConfig*.

[source,xml]
----
<ftConfig
  url="http://10.1.4.116:9933"
  maxResultsPerPage="20"
  fragmentLength="250"
  maxSuggestedTerms="10"
  maxDocLinks="20"
  minDocLinksScore="5"
  automaticallyDisplayPJ="true"
  suggestionEnabled="true"
  searchOnAllTextFields="true"/>
----

[cols="2a,4a,1a,1a",options="header"]
|===
|Attribut|Description|Obligatoire?|Valeur par défaut
|*url*|Url de connexion/d'accès au module {fulltext}|[green]#Oui#|
|*maxResultsPerPage*|Nombre de documents affichés simultanément en page de résultats||20
|*fragmentLength*|Longueur du fragment de résultat (_prévisualisation_)||250
|*automaticallyDisplayPJ*|Afficher automatiquement la pièce jointe en vue résults de _recherche plein-texte_||[green]#true#
|*suggestionEnabled*|Activer la suggestion des mots dans la _recherche plein-texte_||[green]#true#
|*searchOnAllTextFields*|Exécuter la _recherche plein-texte_ sur les [underline]#champs de type *FULL-TEXT*# en plus du contenu des pièces jointes||[green]#true#
|*maxSuggestedTerms*|Nombre de termes proposés lorsque la suggestion des mots est activée par l'utilisateur||10
|*maxDocLinks*|Nombre maximum de résultats remontés lors de la _recherche de documents similaires_||20
|*minDocLinksScore*|Score minimum attendu lors de la _recherche de documents similaires_||5
|===
