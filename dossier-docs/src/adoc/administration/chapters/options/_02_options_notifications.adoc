=== Notifications

[cols="4a,3a,1a,2a",options="header"]
|===
|Code|Description|Type|Valeur par défaut (et/ou _autres valeurs possibles_)
|*misc.notificationMessageTimeoutEnabled*|Timeout d'affichage des notifications|Boolean|[green]#true#
