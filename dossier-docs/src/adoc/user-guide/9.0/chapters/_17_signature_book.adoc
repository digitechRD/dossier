== Signature

Il y a 2 modes disponibles pour la signature, le mode Parapheur et le mode OTP.

=== Mode Parapheur

Dans le mode Parapheur, le signataire a accès à la plateforme de signature où il peut visualiser et signer les documents préalablement envoyés via l'onglet
Signature.

Le parapheur, si disponible, est accessible à partir de la *Vue document* :

.Parapheur
image:17_signature_book/image366.png[width=604,height=460]

Cet onglet est divisé en différentes sections.
Dans la partie gauche, le champ *Document principal* vous permet de choisir via une liste déroulante le
document
que vous souhaitez signer.

Le champ *Circuits* vous permet de déterminer le circuit de validation à utiliser.

On retrouve à droite de cette section le tableau des annexes :

.Annexes à transmettre au parapheur
image:17_signature_book/image367.png[width=604,height=112]

Ce tableau permet, dans le cas où plusieurs pièces jointes sont présentes, de sélectionner celles qui seront associées à cette demande.

Une fois tous les éléments obligatoires renseignés, le bouton
image:17_signature_book/image368.png[] situé dans le coin supérieur droit devient visible.
Vous pouvez cliquer sur
image:17_signature_book/image368.png[] pour envoyer le document vers le parapheur.
Une fois l’envoi effectué, l’écran se met à jour avec notamment deux nouveaux boutons disponibles :

.Parapheur (envoi effectué)
image:17_signature_book/image369.png[width=604,height=333]

* image:17_signature_book/image370.png[] : permet d’actualiser le statut du document dans le cas où l’affichage n’est pas à jour.
L’état du document est décrit dans le tableau *Information/Statut*.
* image:17_signature_book/image371.png[] : permet d’annuler la demande de signature (si cette fonctionnalité est disponible pour le
connecteur).

=== Mode OTP

Dans le mode OTP, l'onglet Signature est un peu différent du mode Parapheur. Sur la partie gauche, vous trouverez le champ *Contact* qui vous permettra de
saisir le nom du ou des signataires, ainsi qu'un espace dédié à la
création d'un nouveau contact si nécessaire.

.Signature
image:17_signature_book/signature.png[]

Dans ce mode, le signataire reçoit un mail contenant le lien vers la plateforme de signature afin de signer le dossier en cours.

.Mail reçu par le signataire
image:17_signature_book/mail.png[]

Si vous suivez le lien et que vous signez les documents, vous recevrez un code à
usage unique par SMS pour valider la signature.

.Saisie du code reçu par SMS
image:17_signature_book/code_sms.png[]
